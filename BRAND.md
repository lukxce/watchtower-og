# Fortress HQ — brand

**This file has moved to [`docs/BRAND.md`](docs/BRAND.md).**

The version that used to live here described the retired "first light" palette
(indigo `#232038` / bone `#faf7f2` / amber beacon) and the old "Keeper" naming.
Both were replaced — by the Glass system (grey-teal scene, teal-green frosted
sheets, highlighter `#eafd35`, ink `#142522`) and by "the Tower".

The three brand laws referenced from code comments — *the tower reads, you
decide* · *the beacon is earned* · *no false fires* — are unchanged and now
live in `docs/BRAND.md` §3.
